# Coding for Justice

A public fairness repair workshop: bring one repeatable unfair process, test a practical repair and publish what actually happened.

## Phase one

The first release provides a public repair and outcome ledger, bounded contribution offers, private proposal and appeal intake, the community covenant and a protected human review area. It deliberately excludes public comments, popularity ranking, uploads, legal casework and automatic AI publication.

The protected workshop also includes a deterministic finish queue and an
optional DeepSeek Flash steward. The model sees public ledger fields only and
can create private drafts; it cannot read private intake or publish anything.

See [the implementation plan](docs/IMPLEMENTATION_PLAN.md) and [the marketing plan](docs/MARKETING_PLAN.md).

## Local development

Install dependencies, apply the local D1 migration and run the development server using the scripts in `package.json`.

Private submissions must never be copied into fixtures, logs, screenshots or external AI tools.
